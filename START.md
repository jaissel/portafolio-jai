# Cómo arrancar en Claude Code

1. Descomprime esta carpeta donde vivirá el repo y ábrela en Claude Code.
2. Copia tu CV en PDF a `public/cv/Jaissel-Perez-CV-EN.pdf` (y el de español cuando lo tengas como `...-ES.pdf`).
3. Pega este primer mensaje:

> Lee CLAUDE.md y PLAN.md. Empieza por la Fase 0 y la Fase 1: crea el proyecto Nuxt 3 en esta carpeta sin borrar lo que ya existe (PLAN.md, CLAUDE.md, content/, design/, public/), configura Cloudflare Pages + D1 y maqueta el home fiel a design/home-mockup.dc.html leyendo el contenido de content/seed.*.json. Al terminar cada fase, muéstrame cómo correrlo en local y marca los checkboxes del plan.

4. Cuando la Fase 1 se vea bien en local, crea las cuentas (Cloudflare, Google AI Studio) y sigue con las fases 2 a 6, una por mensaje.
